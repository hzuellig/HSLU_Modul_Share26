Responsiveness & Media Queries

Wie passt sich ein Layout an unterschiedliche Bildschirmgrössen an — ganz ohne Framework? Zieh unten am rechten Rand, um die Breite live zu verändern.

1. Die Grundlage: viewport-Meta-Tag

Ohne diese Zeile im <head> skaliert ein Handy-Browser die Seite einfach verkleinert, statt sie wirklich neu anzuordnen. Sie gehört in jede Seite: 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

3. Mobile-First vs. Desktop-First

Es gibt zwei Denkrichtungen, je nachdem ob man mit min-width oder max-width arbeitet. Meist empfohlen: mobile-first.

Mobile-first (empfohlen)

/* Basis-Stil = für schmale Screens */
.card { padding: 12px; }

/* ab hier: mehr Platz vorhanden */
@media (min-width: 700px) {
  .card { padding: 24px; }
}

Desktop-first

/* Basis-Stil = für breite Screens */
.card { padding: 24px; }

/* ab hier: weniger Platz vorhanden */
@media (max-width: 699px) {
  .card { padding: 12px; }
}

4. Responsive p5.js-Sketches

Die gleiche Idee funktioniert auch für <canvas>-Grafiken: Statt einer festen Grösse wie createCanvas(400, 400) misst man die Breite des umgebenden Containers und rechnet die Höhe über ein festes Seitenverhältnis aus. Bei einer Grössenänderung des Fensters wird der Canvas neu skaliert.

HTML: Container statt fixer Canvas-Grösse

<div id="p5Sketch"></div>
<script src="sketch.js"></script>

CSS: Container bestimmt die maximale Breite

#p5Sketch {
  width: 100%;
  max-width: 700px;
  margin: 12px auto 0;
}

JavaScript: Canvas an Container-Breite anpassen

let container;
let ratio = 0.75; // Seitenverhältnis, z.B. 4:3

function setup() {
  container = document.getElementById('p5Sketch');
  const canvas = createCanvas(container.clientWidth, container.clientWidth * ratio);
  canvas.parent(container);
}

function draw() {
  background(220);
  // ... Zeichnen wie gewohnt, mit width/height statt fixen Zahlen
}

// wird von p5 automatisch bei jeder Fenstergrössenänderung aufgerufen
function windowResized() {
  const holder = document.getElementById('p5Sketch');
  resizeCanvas(holder.clientWidth, holder.clientWidth * ratio);
}

Wichtig dabei: width und height in draw() nie fest verdrahten, sondern relativ verwenden (z.B. width / 2 für die Mitte), damit die Zeichnung bei jeder Grösse passt.

Zum Ausprobieren
  • Ändere ratio auf 0.5 und beobachte, wie sich die Höhe anpasst.
  • Ändere max-width im CSS und verkleinere das Browserfenster.
  • Ergänze in draw() eine zweite Form, die sich ebenfalls an width/height orientiert.
